# 武汉市老年助餐服务消费状况调查问卷（电子版）

- 面向 60 周岁及以上武汉市常住老年人，匿名填写
- 依据正式问卷 v2（43 题）制作，含 S1/S2 筛选、B1/B3 跳题逻辑、C 区 5 点李克特量表（含注意力检测题 CA1）
- 适老化设计：一题一屏、大字号大按钮、自动跳转、可回退修改
- 作答数据保存在填写者设备浏览器本地，可通过页面底部“数据管理”导出 CSV
